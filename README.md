### 👋 About Me

- 🔭 I build **self-contained single-page apps** — a QR generator, a Tetris clone, a PDF→Word converter — open one file and it just works.
- 🧠 Working across **full-stack web** and **applied Python**: media forensics, prediction models and data dashboards.
- 🧩 Sharpening my **DSA** on LeetCode, CodeChef and Codeforces.
